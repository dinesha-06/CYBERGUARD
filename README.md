# CyberGuard

AI-powered Cyber Threat, Phishing and Digital Threat Detection and Response System.

## Overview

CyberGuard is a modular AI-powered cybersecurity platform designed to detect, analyse, classify and respond to multiple categories of cyber threats.

## Planned Modules

- AI-Powered Phishing Detection
- Credential Theft & Account Takeover Detection
- Malicious URL & Website Detection
- Intelligent Cyber Threat Detection
- Threat Fusion and Risk Scoring
- Explainable Threat Assessment
- Response Recommendation
- Cybersecurity Monitoring Dashboard
